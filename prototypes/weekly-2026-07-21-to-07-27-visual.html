03 / Paradigm Shifts

这周的行业迁移图。

适合做飞书文档里的一张总结图，也适合公众号开头“先给结论”。它把六个趋势压成六组 from-to。

Prompt scaffolding

从给弱模型写保姆手册，迁移到给成熟模型目标、边界和复盘机制。

→ Mature agent management
Pre-release eval

从发布前安全题，迁移到运行时身份、权限、日志、审批和回滚。

→ Runtime boundary
Model ranking

从谁模型最强，迁移到模型、harness、验证器和轨迹的组合能力。

→ Model-system pair
Chat interface

从聊天框回答，迁移到 Excel、Outlook、画布、图片和设计台交付。

→ Artifact surface
Web corpus

从更多网页文本，迁移到任务提出、拆解、执行、修正和验收轨迹。

→ Workflow trajectory
Token price

从 API 价格表，迁移到吞吐、电力、租赁、债务和数据中心协议。

→ Industrial ledger
